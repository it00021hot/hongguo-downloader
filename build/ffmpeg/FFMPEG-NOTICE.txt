FFmpeg and FFprobe —— 第三方组件许可说明
=======================================

本目录中的 ffmpeg / ffprobe 可执行文件随应用分发，用于视频合并和兼容转码。
Windows 使用 Gyan.dev FFmpeg essentials_build；macOS 使用 ffmpeg-static
项目为当前 CPU 架构提供的 FFmpeg，以及 ffprobe-installer 提供的 FFprobe。

macOS 二进制信息
----------------
FFmpeg 来源：https://github.com/eugeneware/ffmpeg-static
FFprobe 来源：https://evermeet.cx/ffmpeg/
对应版本与构建信息见随包分发的 README-ffmpeg-static.md、
FFPROBE-NOTICE.txt 和 LICENSE-ffmpeg-static.txt。

Windows 二进制信息
------------------
版本       : FFmpeg 7.1-essentials_build
来源       : https://www.gyan.dev/ffmpeg/builds/
官方源码   : https://ffmpeg.org/download.html
             https://github.com/FFmpeg/FFmpeg
许可证     : GNU General Public License version 3（GPLv3）

FFmpeg 的源码可从 https://ffmpeg.org/download.html 免费获取。
对应具体二进制版本和构建配置的信息包含在各平台随包附带的许可及 README 文件中。

FFmpeg 是独立的第三方程序，与本软件之间通过命令行调用交互。
本软件仅调用其公开的命令行接口，未修改 FFmpeg 源码。
